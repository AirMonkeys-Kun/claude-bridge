## Deployment Steps (Windows PowerShell)

Run these from `D:\zebbingo\tools\claude-bridge\` as Administrator:

### 1. Register Guard-Dog Scheduled Task

```powershell
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -File `"$pwd\cluster\guard-dog.ps1`""
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 1) -RepetitionDuration ([TimeSpan]::MaxValue)
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -TaskName "BridgeGuardDog" -Action $action -Trigger $trigger -Settings $settings -RunLevel Highest -Force
Start-ScheduledTask -TaskName "BridgeGuardDog"
```

### 2. Start Guardian Manually (First Boot)

```powershell
Start-Process -FilePath "powershell.exe" -ArgumentList "-NoProfile -ExecutionPolicy Bypass -File `"$pwd\cluster\guardian_v3.ps1`"" -WindowStyle Hidden
```

Guardian will:
- Start watcher → workers → bridge_agent → proxy
- Write `.guardian_heartbeat` to watcher dir
- Guard-dog will monitor from next cycle

### 3. Verify

```powershell
# Check guard-dog log
Get-Content "$pwd\watcher\guard-dog.log" -Tail 5

# Check guardian log
Get-Content "$pwd\watcher\guardian_v3.log" -Tail 10

# Check heartbeat
Get-Content "$pwd\watcher\.guardian_heartbeat"
```

### 4. Process Learning Entry

```powershell
python "$pwd\watcher\add_learning.py"
```

### Rollback

```powershell
Unregister-ScheduledTask -TaskName "BridgeGuardDog" -Confirm:$false
# Reset to previous commit:
git checkout HEAD~1 -- cluster/guardian_v3.ps1
```
